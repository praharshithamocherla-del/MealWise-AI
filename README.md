
# 🥗 MealWise AI
**Predict Better. Prepare Smarter. Waste Less.**

MealWise AI is a beginner-friendly end-to-end machine-learning mini project for estimating cafeteria attendance for breakfast, lunch, and dinner. It compares a baseline and three regression models, evaluates prediction errors, and provides preparation recommendations in a Streamlit dashboard.

> **Important:** The included dataset is synthetic demonstration data. It is not collected from a real cafeteria. Metrics from it demonstrate the pipeline only and must not be presented as evidence of real-world accuracy or actual food-waste reduction.

## Features
- Five Streamlit sections: Home Dashboard, Data Explorer, Demand Prediction, Model Performance, Food Waste Insights.
- Data validation and reusable feature preparation.
- Dummy baseline, Linear Regression, Decision Tree, Random Forest.
- Chronological 80/20 train/test split.
- MAE, RMSE, R², actual-vs-predicted and residual plots.
- Transparent, adjustable preparation safety margin.
- Automated tests with pytest.

## Windows / VS Code setup
1. Install Python 3.11+ and Git.
2. Extract this ZIP, then open the `MealWise-AI` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Create an environment:
   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
   If PowerShell blocks activation, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`, then activate again. Or use Command Prompt: `.venv\Scripts\activate.bat`.
5. Install packages:
   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
6. Train models and generate evaluation metrics:
   ```powershell
   python -m src.train
   ```
7. Generate evaluation plots:
   ```powershell
   python -m src.evaluate
   ```
8. Run tests:
   ```powershell
   python -m pytest -q
   ```
9. Launch the app:
   ```powershell
   streamlit run app.py
   ```
10. Streamlit prints a local URL, usually `http://localhost:8501`. Open it in your browser.

## Dataset strategy and replacing the demo data
No real public cafeteria-attendance dataset is bundled or claimed. The supplied `data/synthetic/meal_attendance_synthetic.csv` is synthetic, for safe demonstration and repeatable testing.

To use real data, obtain permission and remove direct identifiers. Keep the same required columns:
- `date`: date of service (`YYYY-MM-DD`)
- `meal_type`: breakfast, lunch, or dinner
- `menu_category`: broad menu label/category
- `attendance`: anonymized total count, not student names/IDs
- `is_holiday`: 0 or 1

Save a backup of the synthetic file, then put approved records at `data/raw/meal_attendance.csv`. Update `DATA_PATH` in `src/train.py` and `src/evaluate.py` to point to that file, retrain, evaluate on a chronological holdout, and document the data source, collection period, permission, and limitations. Ensure each row represents one date/meal and that there are enough records across dates and categories.

## Deploy to Streamlit Community Cloud
1. Push this project to GitHub.
2. Visit https://share.streamlit.io/ and sign in with GitHub.
3. Select **Create app**, choose the repository and branch `main`, and set main file path to `app.py`.
4. Before deploying, run `python -m src.train` locally and commit the generated `models/mealwise_model.joblib` and `models/metrics.json`. If `models/` is empty, Streamlit Cloud will show a helpful message in Demand Prediction until you train and include the artifacts.
5. Deploy and open the generated public app URL. Test all five sections.
6. After changing data or code, retrain locally and push the updated artifacts if needed.

## Common errors
- `No module named streamlit`: activate `.venv`, then `pip install -r requirements.txt`.
- `python not found`: install Python 3.11+, enable PATH, restart VS Code, or try `py`.
- PowerShell activation blocked: use the process-only execution policy command shown above or activate via Command Prompt.
- `Trained model not found`: run `python -m src.train` from the project root.
- Missing columns: check the CSV schema and exact column names.
- App is blank or cannot start: read terminal traceback; make sure VS Code's interpreter is `.venv`.
- Cloud prediction unavailable: ensure the trained model artifact was committed and pushed.

## Viva questions
**1. What is MealWise AI?** A prototype that predicts expected meal attendance and recommends a preparation quantity.
**2. Why use regression?** The target is a numeric count of expected students.
**3. What is MAE?** Average absolute difference between actual and predicted attendance.
**4. What is RMSE?** An error metric that penalizes large errors more strongly.
**5. Why a DummyRegressor?** It is a simple baseline to check whether ML adds value.
**6. Why split chronologically?** It better simulates predicting future dates from past observations.
**7. What is data leakage?** Using information that would not be available when a prediction is made.
**8. Why synthetic data?** It allows the app and pipeline to be demonstrated before approved real data is available.
**9. Does a predicted surplus equal food waste?** No. Waste requires measuring leftovers/discarded food.
**10. How can it improve?** Train and prospectively evaluate with sufficient anonymized real attendance and leftovers records.
